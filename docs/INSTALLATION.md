# DigitalBots Installation

## Windows desktop client

1. Download and extract the **built** `DigitalBots_Installer.zip` artifact from the Windows build workflow.
2. Confirm the extracted folder contains `DigitalBotsSetup.exe` and `install.bat`.
3. Run `install.bat`. It starts the signed or unsigned per-user NSIS installer generated by Tauri.
4. Finish the installer. The NSIS hook creates `DigitalBots.lnk` on the current user's Desktop; the normal Tauri Start Menu shortcut is also installed.
5. Open DigitalBots from the Desktop shortcut.
6. On first launch, enter your main server HTTPS address, for example `https://manage.yourdomain.com`.
7. Sign in with your DigitalBots administrator account. Client data is stored on the main server.

The desktop client does not require Node.js, MySQL or HeidiSQL. It uses the Windows WebView2 runtime; the Tauri installer is configured to download the WebView2 bootstrapper if needed.

## Main web server

The web application must be deployed separately to your central server before desktop clients can connect. Follow `MAIN_SERVER_DEPLOYMENT.md`. Do not enter a made-up server address in the desktop client.

## First administrator setup

The first browser visit to the main server displays the one-time administrator setup screen. Enter the `INITIAL_SETUP_KEY` configured in the central server environment. The username is fixed to `digitalbots`; choose a new password of at least 14 characters. The setup request is one-time and the initial network IP is registered as trusted.

## Local development

From the project root:

```bash
cp .env.example .env
# Edit .env with your local MySQL connection and a long random SESSION_SECRET
npm install
npm run build:web
npm run db:migrate
npm start
```

Then open `http://127.0.0.1:6767/desktop6767`.

## If the Windows setup executable is missing

Do not run a partial install. A source package intentionally stops and explains the missing binary. Build the real NSIS executable using `docs/WINDOWS_BUILD.md`, or download the workflow's generated installer artifact.
